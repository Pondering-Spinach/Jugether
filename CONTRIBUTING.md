# Contributing to Jugether

Contributions are welcome! You can report a bug, suggest an improvement, or open a pull request through [GitHub issues](https://github.com/Pondering-Spinach/Jugether/issues) and [pull requests](https://github.com/Pondering-Spinach/Jugether/pulls). For larger changes, consider opening an issue first so we can discuss the approach.

## Before submitting a pull request

1. Read the [README](README.md) for local setup. Install dependencies in both `frontend/` and `backend/`, then run `npm run db:migrate` and `npm run dev` from `backend/`.
2. Keep changes focused and explain how you tested them. Run `npm run build` from `backend/` (this builds the frontend and type-checks the backend). Include manual reproduction steps for UI or playback changes.
3. Do not commit passwords, YouTube cookies, database files, generated builds, or other secrets.
4. Respect the [project license](LICENSE.md). By submitting a contribution, you agree to license your contribution under the same PolyForm Noncommercial 1.0.0 terms. You retain copyright in your contributions; no copyright transfer or CLA is required.
